Списки

Нумерованный список ― Order List

Создается дескриптором <ol>.

  1. Элемент 1;
  2. Элемент 2;
  3. Элемент 3;
  4. Элемент 4;
  5. Элемент 5;

Маркированный список ― Unorder List

Создается дескриптором <ul>.

  • Элемент 1;
  • Элемент 2;
  • Элемент 3;
  • Элемент 4;
  • Элемент 5;

Элементы списка ― ListItems

Как в нумерованном, так и в маркерованном списке элементы создаются дескриптором <li>

Список определений ― DefinitionList

Создается дескриптором <dl>, что означает Description List.
Каждый элемент списка описывается 2-мя дескрипторами: <dt> ― Description Term и <dd> ― Description Details.

Нумерованный список
Каждый элемент такого списка имеет точный порядковый номер;
Маркированный список
Каждый элемент такого списка обозначен каким-то символом;
Список определений
Каждый элемент такого списка вводит в понятие и дает ему определение;

Вложенность

Списки можно вкладывать в друг друга как угодно, НО, вкладывать список непосредственно в другой список ЗАПРЕЩЕНО!!! Список можно вкладывать только в элемент другого списка!!!
